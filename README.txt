DARK LIFE — BUILD 0.3

Состав:
- index.html — приложение
- manifest.webmanifest — настройки установки PWA
- sw.js — офлайн-кэш
- icon-192.png / icon-512.png — иконки

Публикация через GitHub Pages:
1. Создайте публичный репозиторий dark-life.
2. Загрузите ВСЕ файлы из этой папки в корень репозитория (не ZIP).
3. Settings -> Pages -> Deploy from a branch -> main -> /(root) -> Save.
4. Откройте опубликованный HTTPS-адрес в Chrome на Android.
5. Меню Chrome -> Установить приложение / Добавить на главный экран.

Ограничения BUILD 0.3:
- Данные сохраняются локально в браузере/на устройстве.
- Аккаунты, облачная синхронизация, реальные платежи и внешние музыкальные сервисы ещё не подключены.
- DARK MUSIC сохраняет аудиофайлы в IndexedDB браузера на устройстве; удаление — вручную из библиотеки. Очистка данных браузера может удалить музыку.
- PRO имеет демонстрационное переключение тарифов; реальные платежи и автопродление не подключены.
